# بوت الفهرس الشخصي 📚

بوت تيليجرام يفهرس أفكارك وملاحظاتك تلقائياً باستخدام الذكاء الاصطناعي.

## الميزات
- 📝 فهرسة الرسائل النصية
- 🎙️ تحويل الرسائل الصوتية لنص وفهرستها
- 🔗 فهرسة الروابط والمقالات
- 🔍 البحث في الفهرس
- 📊 إحصائيات

## الأوامر
- `/فهرس` — عرض الفهرس الكامل
- `/بحث [كلمة]` — البحث
- `/احصاء` — الإحصائيات
- `/مساعدة` — المساعدة
